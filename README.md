# Kirana Stores Sales Dashboard
This project shows total sales of a Kirana Store using Excel.

# What I Did
-Created Sales Data in Excel
-Created PivotTable to find Sales by Category
-Create PivotChart to visualize Sales

# Key Findings
-Total Sales:Rs.13,194
-Grocery Sales:Rs.9,915
Daily Needs Sales:Rs.2,809
Snacks Sales:Rs.470
